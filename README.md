# 🎀 Aisana 16 Birthday Site

Айсана / Айсанек үшін туған күн сайты.

## Файлдар

- `index.html` — негізгі бет
- `style.css` — дизайн және анимациялар
- `script.js` — confetti және countdown
- `assets/aisana.gif` — өз GIF файлың осында орналасады

## GIF қою

Өзіңнің GIF файлыңды `assets` папкасына салып, атын дәл `aisana.gif` деп өзгерт.

## GitHub Pages

Репозиторийдің Settings → Pages ішінен:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

Сақтағаннан кейін GitHub Pages сілтемесін көрсетеді.
